Configurar el tablero

Aquí se ponen las dos contraseñas (una para ver y otra para editar) y la llave de GitHub. Todo se cifra en tu navegador: ni las contraseñas ni la llave salen de aquí.

  1. En GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → odoo-priat-tablero.
  3. Permissions → Repository → Contents: Read and write. Nada más. Expiración: la que prefieras.
